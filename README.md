# ResumeAI — Agentic Resume Customizer

An AI-powered resume tailoring tool built with LangGraph multi-agent orchestration. Upload your resume, paste a job description, and let the agents rewrite and optimize it for ATS.

---

## Features

- **Multi-Agent Pipeline** — Six specialized AI agents working in sequence via LangGraph
- **ATS Optimization** — Rewrites bullet points and summary to match job description keywords
- **Skills Gap Analysis** — Identifies matched, partial, and missing skills at a glance
- **Quality Review Loop** — Reviewer agent scores output and retries rewriting if quality is below threshold
- **Disk Caching** — Resume parse and JD analysis results are cached to reduce token usage
- **Real-time Status Updates** — Live agent progress shown in UI while pipeline runs

## Agent Architecture

```
JD Analyzer → Resume Parser → Skills Matcher → Rewriter → Reviewer
                                                               ↓
                                                    (approved?) → Final Output
                                                    (retry?)    → Rewriter ↑
```

| Agent | Responsibility |
|---|---|
| JD Analyzer | Extracts required skills, responsibilities, and company tone from job description |
| Resume Parser | Reads PDF resume and structures it into sections (experience, projects, skills) |
| Skills Matcher | Compares JD requirements vs resume skills — categorizes as matched, partial, or missing |
| Rewriter | Rewrites summary, experience bullets, and project bullets to align with JD |
| Reviewer | Scores rewritten resume on ATS, clarity, tone, and keyword match — triggers retry if below threshold |
| Orchestrator | LangGraph StateGraph that manages state, routing, and retry logic |

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/miku1001/HireGenie.git
cd HireGenie
```

### 2. Create and activate virtual environment

```bash
python -m venv .venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up environment variables

Create a `.env` file in the root:

```env
OPENROUTER_API_KEY=your_api_key_here
```

Get your API key at [openrouter.ai](https://openrouter.ai) — free tier available.

### 5. Run the app

```bash
streamlit run app.py
```

## How It Works

1. Upload your resume as a PDF
2. Paste the job description you're applying to
3. Click **Customize My Resume**
4. The pipeline runs through all six agents in sequence
5. Results show:
   - Match scores (ATS, Clarity, Tone, Keywords)
   - Skills breakdown (matched / partial / missing)
   - Rewritten professional summary
   - Rewritten experience bullet points
   - Rewritten project descriptions
   - Specific improvement suggestions

## Caching

Resume parsing and JD analysis results are cached using `diskcache` to avoid redundant LLM calls:

| Agent | Cache TTL |
|---|---|
| Resume Parser | 24 hours |
| JD Analyzer | 12 hours |
| Skills Matcher | 12 hours |

Cache is keyed by MD5 hash of file/text content — same resume uploaded twice hits the cache automatically.
